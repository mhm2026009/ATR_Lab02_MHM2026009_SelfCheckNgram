## Problem and research questions
A cheap, zero-resource hallucination detector would be a prerequisite for abstention (a gap listed in my review). I study the unigram variant of
SelfCheck-NGram (official `selfcheckgpt` package) on `potsawee/wiki_bio_gpt3_hallucination` (238 biographies, 1,908 labelled sentences).
* **RQ1** How do AP/AUROC change with the number of sampled passages k = 5, 10, 20?
* **RQ2** Does it beat trivial controls (sentence position, length, random)?
* **RQ3** Major vs minor inaccuracies, and how sensitive is a threshold chosen on the same data?

Pathway B (controlled comparative study). No novelty claim. The protocol was fixed **retrospectively** (see `research_decisions.md`).

## Headline results (all from `results/tables/`, regenerated by the scripts below)
| | AUROC (95% CI) | AP |
|---|---|---|
| SelfCheck-NGram k=5 | 0.589 (0.552-0.624) | 0.777 |
| k=10 | 0.629 (0.595-0.665) | 0.800 |
| k=20 | 0.655 (0.621-0.688) | 0.815 |
| Control: sentence position | 0.582 (0.555-0.611) | 0.774 |
| Chance | 0.500 | 0.730 (= prevalence) |

At k=5 the detector is statistically tied with the position control (paired AUROC diff +0.007, CI -0.036 to 0.047). Full discussion in `paper/main.pdf`.
